## 关键坑
- 这个仓库 git 分支 ref 文件会莫名消失（HEAD 指向 refs/heads/feature/tv-netflix-live 但文件不在），且 ref 必须写完整 40 位 hash（短 hash 会导致 show-ref 报全 0）。修复方式：`printf '%s\n' <40位hash> > .git/refs/heads/feature/tv-netflix-live`（mkdir -p 父目录）
- git 操作偶发 index.lock 残留，需 rm -f .git/index.lock
- Windows bash 里 curl 走 schannel，访问 github.com/api 需加 -k
